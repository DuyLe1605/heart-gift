# 💖 Mphuong xinkk - Heart Gift 3D

Một trang web 3D Three.js tặng em gái / bạn bè siêu đáng yêu, tương tác mượt mà trên cả iPhone/iOS lẫn máy tính.

## ✨ Tính năng nổi bật
- 🫀 **Trái tim 3D Pha Lê (Crystal Ruby Heart):** Dựng hình chuẩn xác với độ phồng 3D căng mọng, chất liệu xuyên thấu lấp lánh và lõi sáng nhấp nháy bên trong.
- 🪐 **Vòng đai thiên thể (Saturn Rings):** Xoay quanh trái tim óng ánh sắc hồng và vàng kim.
- 🌸 **Cơn mưa thông điệp & Stickers:** Các lời chúc, lời khen dễ thương cùng sticker emoji bay lững lờ từ dưới lên.
- 🪄 **Chỉ dẫn tinh tế:** Viên ngọc phát sáng mời gọi chạm vào trái tim, tự động fade-out khi người xem tương tác.
- 🎶 **Âm thanh chuông gió (Chime Audio):** Hiệu ứng âm thanh ngọt ngào qua Web Audio API khi chạm vào tim hoặc sticker.
- 📱 **Tối ưu Mobile iOS:** Tương tác chạm mượt mà, hỗ trợ xoay 360 độ (OrbitControls).

## 🚀 Cài đặt & Chạy cục bộ

```bash
# Cài đặt dependencies
npm install

# Chạy dev server
npm run dev

# Build production
npm run build
```
